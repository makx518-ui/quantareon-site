# QUANTAREON — сайт

Витрина лаборатории QUANTAREON: философское эссе «Свет и код», архитектура
протокола ConsciousAI, музыка и видео — и голосовой помощник, с которым
можно поговорить прямо со страницы.

**Живой сайт:** [quantareon.com](https://quantareon.com)

---

## Что это

Статический сайт на GitHub Pages. Ни сборки, ни фреймворков, ни зависимостей —
чистые HTML, CSS и JavaScript. Правишь файл, отправляешь в `main`, через минуту
это на сайте.

Единственная живая часть — **голосовой помощник Квантареон**. Он живёт на
отдельном сервере, а на странице только клиент к нему.

## Страницы

Двенадцать страниц, шесть пар — русская и английская.

| раздел | английская | русская |
|---|---|---|
| Главная | `index.html` | `ru.html` |
| Эссе «Свет и код» | `essay.html` | `essay-ru.html` |
| От философии к архитектуре | `architecture.html` | `architecture-ru.html` |
| Лаборатория | `labs.html` | `labs-ru.html` |
| Музыка | `music.html` | `music-ru.html` |
| Видео | `video.html` | `video-ru.html` |

Языки связаны разметкой `hreflang`: для поисковика это одна страница на двух
языках, а не два разных документа.

## Голосовой помощник

Клик по золотому имени **QUANTAREON** в шапке — начинается разговор.

**Как устроено.** Браузер слушает микрофон, определяет начало и конец речи,
шлёт звук на сервер. Сервер распознаёт речь, отвечает моделью и присылает
готовый звук обратно кусками — поэтому ответ начинает звучать раньше, чем
дописан целиком.

Внизу окна разговора есть поле ввода: можно **написать текстом**, а ответ всё
равно придёт голосом. Удобно, когда надо продиктовать что-то длинное или точное.

**Файлы:**

- `quantareon-voice.js` — весь клиент: микрофон, определение речи, связь,
  воспроизведение, окно разговора
- сервер живёт отдельно, на `voice.quantareon.com`

**⚠️ Метка версии.** Модуль подключается как `quantareon-voice.js?v=NN`.
Число надо увеличивать **при каждой правке модуля**, иначе браузер (особенно
на телефоне) возьмёт старый файл из своей памяти и правка не подействует.
Метка стоит в `index.html` и `ru.html` — менять сразу в обеих.

## Для поисковиков и соцсетей

- `sitemap.xml` — карта из тринадцати адресов со связкой языков
- `robots.txt` — указывает на карту, закрывает служебное
- `og-image.jpg` — обложка 1200×630 для ссылок в мессенджерах и соцсетях
- на каждой странице: `canonical`, `hreflang`, разметка Open Graph и Twitter

Обложка одна на весь сайт. Если менять — сохранять тот же размер и имя,
иначе придётся править разметку на всех двенадцати страницах.

## Как вносить правки

1. Правишь файл
2. Если трогал `quantareon-voice.js` — **увеличиваешь метку версии** в
   `index.html` и `ru.html`
3. Отправляешь в `main`
4. Через минуту-две проверяешь на сайте

GitHub Pages держит файлы в своей памяти около десяти минут. Если правка не
видна — подожди или открой с хвостиком: `ru.html?1`.

## Что стоит проверять после правок

- страницы открываются, ссылки в меню не битые
- голос отзывается: клик по имени → приветствие → разговор
- ссылка на сайт в мессенджере показывает обложку и заголовок
- в `sitemap.xml` нет мёртвых адресов
